# TURN 正式关卡盘点

表格按当前的选关顺序排列。货舱 02 使用开场教学版，其余地图与敌人配置以 `21e8583` 的实载结果为准。共有 **11 个关卡入口**，对应 **10 张独立地图**。其中有 **6 个常规战斗关、1 个战斗验证关、4 个可探索的场景**。

| 标记 | 含义 |
| --- | --- |
| **优先重构** | 场景仍显简陋，或关键视觉主体仍是占位。 |
| **适合补强** | 主要布局已经成形，局部还需要加强辨识度、灯光或细节。 |
| **基础较完整** | 场景主题与路线已经清楚，可在现有布局上继续制作。 |
| **复用地图** | 沿用另一关的地图，这一关主要维护自己的敌人和战斗配置。 |
| **已重构** | 已按当前剧情流程制作新版场景。 |

- **灯墙之厅**的主要缺口是 Boss 出场空间与墙面、入口的层次。
