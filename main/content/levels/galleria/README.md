# ORION // Galleria 坠击中庭

正式第二关从货舱 02 气闸另一侧开始。上层通廊、中央坠击缺口、右侧返程楼梯和下层实验室门厅构成主线。下层有 **2 名 ARC Sentinel 和 1 台单轮巡射机甲**。

货舱最后一道压力门开启后，玩家过门进入中庭上层。三名敌人开场开始追踪玩家，楼层高差和实体遮挡仍会限制出招。青色箭头引到坠击入口。打完三名敌人后，实验室门开启，穿过门槛进入回廊实验舱。

正式场景陈设维护在 [campaign_arena.gd](src/encounter/campaign_arena.gd)。测试场景与共享楼梯导航参数维护在 [arena.gd](src/encounter/arena.gd)。

## 启动

Windows 双击仓库根目录的 [启动试玩.cmd](../../../../启动试玩.cmd)，然后选择「坠击中庭」或「坠击中庭 · 高低差」。也可先从仓库根目录运行 `python main/tools/prepare_game.py`，再用 Godot 4.7.2 打开 `main/project.godot`。

## 高台进攻

1. 玩家在货舱气闸内侧进入中庭。沿青色箭形灯经过上层通廊，到中央缺口后按 Space 起跳或直接走下边缘。
2. 从高台进入空中后按 **鼠标左键**，发动带刀身动作与激光轨迹的坠击；落地形成冲击环，对半径 7 场景单位内、无遮挡的敌人造成 90 点伤害。
3. 坠击需要从至少 6 单位高处起步，并实际下落至少 3 单位；普通原地跳跃不会反复触发冲击伤害。无需按键也可正常落地，继续使用原有方向斩和弹反。
4. 落地后利用下层柜台、隔板和立柱绕侧，接近后排远程怪。右侧宽阶梯可返回高台，重新选择下落位置。
5. 清空三名敌人后，实验室门升起。沿重新亮起的青色箭头穿过门槛，进入第三关。按 R 重开，死亡也会重开。

## 第 10 关 · 高低差

选关中的「坠击中庭 · 高低差」使用原有测试布局。下层中央有一名 1 点生命的人形刀客，玩家从高台生成，可从中央开口跳下，沿右侧阶梯返回。

开场低位蓄力结束后，如果玩家仍在高台，刀客会从右侧楼梯跑上来，最后落脚接原来的二连斩。在楼梯中间接敌时，出招会检查双方高差和刀路。玩家离开踏面时，刀客先沿上一个落脚点追击，等玩家落地后再改路线。

击倒刀客后通关。在无遮挡处用刀终结刀客时，会切到第三人称。镜头从起手动作切入，以 0.055 倍速起步，刀刃在接触前逐渐加速。命中后以 0.17 倍速连续播放 1.12 秒，再平滑恢复原速。空地上刀客会沿刀势击飞，镜头跟随到脱手落刀和机甲砸地。按 **R** 恢复初始站位。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 鼠标 | 移动 / 转动视角 |
| Space / Shift | 跳跃 / 冲刺 |
| 鼠标左键 | 地面攻击；高台下落时发动坠击 |
| 左键 + A / D / S | 方向斩 |
| 鼠标右键 | 弹反、举刀 |
| Q / E | 重斩 / 回旋斩 |
| F | 查看附近设备的交互提示并操作 |
| V / Tab | 第一、第三人称切换 / 第一人称视野遮罩 |
| R / Esc | 重开 / 暂停及按键设置 |
| F1 / `~` | HUD 开关 / 手感参数 |

普通斩击走视野格挡流程。高台坠击的落地冲击只检查落点距离和实体遮挡，独立结算范围内的伤害。

气闸出口左侧的无文字地图按 F 点亮。红点跟随存活敌人，击倒后红叉留在原位置。补给台的查验柜会打开挡板，展示从货舱 02 转入的减振件和备用电芯。实验室左侧终端读取安全联锁，显示仍处于警戒的敌人数量，并在门打开后显示通行状态。提示贴在对应设备上，交互键和货舱 02 共用设置。

## 场景与实现

货舱侧的压力门和上层观察廊沿用第一关的低饱和冷钢和青色路线灯。下层补给区用铜色工棚、暖工作灯和辊道标识，休息区用圆顶、软座和蓝灰地坪标识，研究区用高门柱和冷青竖灯标识。28 级浅踏步连接下层和高台，楼梯外侧有可走通的通道。正式关的移动范围由实体墙、栏杆和其他场景物件确定，墙角按主角圆形足迹计算。旧测试关沿用原有几何与照明，VoxelGI 缓存存放在 Godot 的 `user://` 用户数据目录。

- `src/encounter/campaign_arena.gd`：第二关布景、敌人位置、实验室门结构。
- `src/encounter/arena.gd`：第十关测试布局和共享楼梯导航参数。
- `src/encounter/art.gd`、`gfx/encounter/`：与货舱一致的实体构件和程序化材质。
- `src/encounter/level.gd`：高度支撑、扫掠碰撞、坠击、寻路和独立通关流程。
- [共享 VESPER 主角](../../characters/vesper/README.md)：接受关卡传入的地面高度，支持高台起跳、落地和接触阴影。
- `src/game/projectiles.gd`：三维实体遮挡，箭可越过低掩体，平台也能挡箭。
- `src/game/camera.gd`：结合关卡三维实体限制相机，避免把矮掩体当作无限高墙。

平台与阶梯的渲染、支撑和碰撞来自同一组尺寸。正式关按实体踏面计算敌人落脚高度，履带底盘和轮缘分别沿自身接触范围修正高度。提交时不要加入 `.godot/`、截图、日志和临时测试脚本。
