# 货舱 02

TURN 的第一关，从统一工程的「开始游戏」或「关卡选择」进入。场地尺寸为 **84 × 92 × 20 场景单位**。出生箱、低顶理货区、高挑装卸厅和东北气闸组成开场路线。

C-02 外侧采用普通货箱编号。出箱后，地面补给先经过扫描滚道，再进周转架。批次 017 在扫描架的一体小屏显示验收状态，与箱签对应。壁柜和沿墙管线提供货舱供电，分拣台陈列同型 ARC Sentinel 拆下的三角履带总成、备用导轮和拆下的刀具夹头。开场切回第一人称后，工作间亮起青色地面指引，带玩家进入主舱。低托盘和箱面支持跳上落脚。

主装卸厅的吊机、挂货、控制台和 A、B 两处落货位共用 LIFT 01 标识。靠近控制台正面按 F，吊机会在货区侧的两个货位间搬运。目的货位腾空后才落货。面向直梯靠近，看到梯侧 F 后抓梯，按 W 上行或 S 下行。到顶后沿落脚板进入栈道，栈道端部的短梯通往吊机纵轨检修工位。玩家跨过装卸门槛后，D-03 检修侧舱响起局部警报并升起卷门，一只 ARC Sentinel 从停放位进入装卸厅。击倒后全舱警报启动，Nova 发来路线，玩家穿过人员气闸后进入第二关坠击中庭。升降门的门片位置、物理碰撞和刀身地形判定同步，净空足够时更新导航通行状态。

装卸厅保留了原箱位。正对 H02 / 05、06、08 的卷门靠近时按 F，可分别查看密封件与滤芯、正在成形的备用义体、ARC 底盘备件。卷门向上收进门楣，重新开始关卡时复位。
