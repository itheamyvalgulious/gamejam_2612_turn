# 货舱 02

TURN 的第一关，从统一工程的「开始游戏」或「关卡选择」进入。场地尺寸为 **84 × 92 × 20 场景单位**。出生箱、低顶理货区、高挑装卸厅和东北气闸组成开场路线。

Sivi 出箱后可练习移动和试刀。越过装卸区转角会出现一名 ARC Sentinel，第一次正面攻击被格挡时由 Nova 解释红眼机制。击倒哨兵会开启警报和撤离箭头，穿过东北人员气闸才记录通关并进入坠击中庭（第 2 关）。

- [场地和碰撞](src/cargo_hold2/arena.gd)管理舱板、箱组、灯具、门和撤离线路。
- [开场与撤离流程](src/cargo_hold2/level.gd)管理敌人、警报和通关触发。
- [字幕与操作提示](src/cargo_hold2/briefing.gd)管理 Nova 通讯和首次教学。
- [货舱着色器](gfx/cargo_hold2/)沿用 TURN 的深紫金属、冷青导向和工业材质。警报光叠加在基础照明上。

修改后用 `python main/tools/prepare_game.py` 更新运行资源，再从 [统一工程](../../../project.godot) 进入第一关。
