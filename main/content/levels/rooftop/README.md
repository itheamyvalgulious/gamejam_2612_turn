## 路线

> 起点 → 垃圾箱 1.0 → 集装箱 2.0 → 屋顶机组 3.0 → R1 3.6
> → 跨 3.8 m → R2 4.4 → 跨 3.8 m → R3 3.4 → 跨 4.0 m → F 4.2

- 攀爬三步各 1.0 m，跳跃高度 1.5 m，留 0.5 m 余量。
- 三处空隙都低于满速起跳的可用距离；掉下去落回 0 m 大屋面，可走回攀爬点重来。
- 起跳边缘有黄黑警示带，落点内侧有黄色落点线。

## 碰撞约定

引擎不用网格碰撞，只认：

- `cover`：竖直圆柱（侧面挡人，`c.y` 是底、`h` 是相对高度）
- `platforms`：轴对齐矩形台面（只能站，不挡侧面）

本关每个可站实体都同时登记两者，且侧墙只到 `top − 0.3`：站在台面上侧墙不再推人，
走出边缘会正常掉下去。可站台面必须满足「台面半径 > 侧墙推开距离」，否则玩家会被
一直推在外面、永远落不上去（窄圆柱顶就是这种情况，所以排风帽都做成 2.2 m 立管，
不做可站台面）。

本关通过 `main/tools/rooftop_check.gd` 检查：

- 15 个路线节点的台面高度与侧推
- 每个台面至少有一个能站住的采样点

当前结果：路线异常 0，无法站立的台面 0。
