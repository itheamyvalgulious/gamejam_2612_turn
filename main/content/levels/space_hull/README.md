# 轨道船背（space_hull）

> **状态：场景初稿，完全未打磨。**
> 不含敌人、波次、刀客、Boss、音效和主程序接入；仅供剧情/路线评审。

飞船外壳第一稿，给剧情同学看空间和战斗分段，**只做场景**：没有敌人、Boss、音效。

## 一句话

主角从船尾炸开的实验室落到背脊甲板，沿 190 m 的船背经过三段战斗区、
两道高架栈桥，拆掉三段供能节点、解除防空封锁，最后抵达船头的船坞大门。

## 空间

- 船体：长 260 m、宽 44 m、高 36 m 的整体静止飞船；壳顶 y=0。
- **背脊甲板在 y=4.0**，比船壳高 4 m，下面能看到承力桁架；船壳在脚下，
  两侧是开放的太空。整体路线保持水平，不做上下坡。
- 路线：实验室平台 x=-8…0 → 战斗 A 0…30 → 桁架 1 30…80 →
  战斗 B 80…110 → 桁架 2 110…160 → 战斗 C 160…190 → 船坞大门 x=190。
- 桁架段是 6.8 / 8.0 m 宽的高架栈桥，三处 3 m 断口；掉下去会落到壳顶 y=0，
  由 `main.gd` 送回最近检查点。
- 终点门是船坞现成的 **30 × 16 m** 舰载机大门（门扇、加强筋、中缝、撞痕、
  黄黑门槛），门后接船坞 Boss 关。
- 背景：近地轨道地球（程序化海陆云 + 昼夜线 + 大气边）、星空、背后的硬太阳；
  没有雾。

## 防空门禁（这一版的剧情改法）

- 每段战斗区尽头有一对防空炮 + 一道红色光闸；炮的供电来自区内的**供能节点**。
- 设计流程：清完本区所有怪 → 供能节点可交互 → 按住约 3 s 拆除 →
  炮塔和光闸断电 → 才能进入下一段。
- 场景初稿没有敌人，所以：
  - 走到琥珀色桅杆旁**按住 `F` 约 2.5 s** = 模拟“拆供能节点”；
  - **`F8` = 立刻切全部断电**，快速预览；
  - **`F10` = 初稿调试传送**，依次跳到下一个检查点（0→1→2→3→4），省得每次从实验室重走。
  真正“清完怪才可交互”和 3 s 进度由主程序接；节点上的五格灯就是给进度留的。
- 走进通电光闸会被推回检查点，并提示先拆供能节点。
- **红色光闸是有意设计的门禁，不是栏杆**：它由上下发射轨、门柱和红色光条组成；
  初稿没有敌人，所以用 `F` 长按或 `F8` 预览断电。光闸门面高 4.4 m，
  炮塔顶（6.59 m）也翻不过去，不要试图从炮塔上跳过门。

## 碰撞与可站面

- 甲板 / 栈桥台面：y=4.0，轴对齐平台。
- 1.25 m 矮护墙：实体、可站，顶面登记平台；1.85 m 漏斗墙只挡不站。
- 箱体：高于甲板 1.5 m 以内的都登记台面；2.4 m 以上的货箱/机柜只挡不站。
- 炮塔、供能节点：整座按圆柱挡人，不登记台面（座圈被炮体占满）。
- 门禁门柱：小外伸台上，有碰撞。

## 文件

- `src/arena/space_hull_arena.gd`：全部空间 / 材质 / 碰撞 / 门禁状态。
- `src/arena/space_aa.gd`：防空通电/断电的材质与灯切换。
- `src/arena/space_sky.gdshader`、`earth.gdshader`：星空与地球。
- `src/main.gd`：第一视角、检查点、跌落/门禁复位、F8 预览。
- `main/tools/space_play.tscn`、`space_look.tscn`：直入和取景工具（仅本地）。
