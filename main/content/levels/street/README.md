# 霓虹街道 · 草稿

> **这是灰盒草稿，不是最终关卡。**
> 目的是先把「车流穿行的大街」这个场景立起来，验证尺度、过街节奏和镜头，
> 美术、车辆碰撞、红绿灯都还没做。可以按下面的流程试玩并提意见，但不要当作完成品。

主街 160 m（东西向），街宽 26 m：路面 16 m（四车道）+ 两侧人行道各 5 m。
出生在西端人行道，走到东端街角即通过。

## 现在有什么

| 部分 | 状态 |
| --- | --- |
| 主街 | 160 m，两侧程序化店面（橱窗灯箱、霓虹灯带、高层窗格） |
| 车流 | 4 条车道、36 辆车循环行驶（每车道 3 组 × 3 辆），有前灯/尾灯 |
| 过街 | 两处斑马线：x = −60 m（带中央安全岛）、x = 20…34 m（十字路口四条） |
| 十字路口 | 南北支路延伸到 40 m，尽头封墙；**支路还没有车** |
| 装卸区 | x = −40…−30 m，北侧凹进 6 m：0.8 m 平台、两只货箱、门洞顶板 |
| 过关 | 进东端青色环 → 本关通过 |

## 怎么跑

三种方式任选：

```bash
# 1. 直接从整包里进：./start.sh（或双击 启动试玩.cmd）→ 关卡选择 → 霓虹街道（草稿）
# 2. 本目录当独立工程跑（macOS / Linux）
./run.sh
# 3. Windows
run.cmd
```

操作：WASD 移动，Shift 冲刺，空格跳跃，V 切换第一/第三人称，R 重开，Esc 暂停。

## 还没做（按优先级）

1. **车辆不碰撞玩家** —— 现在穿过车不会受伤，过街压力只来自视觉；
2. **支路没有车流** —— 需要先有红绿灯，否则南北车流会和主街车流交叉穿模；
3. 车辆造型统一、颜色单一，缺少车型差异；
4. 装卸区内部偏暗，灯光射程不够；
5. 雨只覆盖街道中心约 40 m，两端没有雨；
6. 没有敌人（这是场景关，敌人配置要看主程序的关卡安排）。

## 设计依据

尺度不是拍脑袋定的：主角跳跃峰值 1.48 m、跑速 5.2 m/s、空中操控 0.45、
第三人称镜头 7.11 m，街宽 26 m 才能保证贴人行道时镜头不撞墙。
过街窗口按「冲刺 7.66 m/s 穿 14 m 需要 1.8 s」设计，车流组间空档约 4.3 s。

## 文件结构

| 路径 | 内容 |
| --- | --- |
| `src/main.gd` | 主循环（从 `levels/city` 复制，强制第三人称，HUD 提示改为移动/跳跃） |
| `src/encounter/arena.gd` | 地图：路面、人行道、楼体、斑马线、安全岛、路口、装卸区、路灯 |
| `src/encounter/level.gd` | 关卡流程：无敌人，进终点判定 |
| `src/traffic/street_traffic.gd` | 车流：四车道循环 |
| `src/encounter/art.gd`、`mesh_kit.gd` 等 | 与霓虹街区共用的建模与材质工具（随本目录复制） |
| `gfx/` | 与霓虹街区共用的表面与霓虹着色器（随本目录复制） |

本关从「关卡选择」进入，参数与界面跟其他关卡一致；`main/` 的构建脚本会自动把它
和其余关卡打进同一个运行包。
