# 回廊实验舱

第三关。玩家沿坠击中庭闸门后的通道进入实验室，经中央收容装置两侧的环廊抵达舱尾控制室。大厅部署三台 Shard Phantom，西侧有三台可选的档案终端，环廊设有光学检查门、档案工作台、相位校准区和吊装检修区，分别以设备结构、地坪和照明识别。东侧设备接入总管，检修区的低托盘和作业台可跳上。主厅净宽、净深均约 65.6 米，净高约 14.8 米。中央收容舱沿用玻璃和液体材质，将旧版观察窗、监控臂、环形线条和低检修平台分别改为高位观察带、扫描探头、管轨与落地检修工位。

中央舱中有一台固定在测试架上的 Shard Phantom。靠近玻璃舱外的控制台，按交互键扳动两档拉杆。观测光路打通时，样机甲片沿原位置稍微散开；落下挡板后，甲片重组。舱内和控制台共享同一组观测与响应曲线。样机使用团队模型，按陈设维护。

从 [TURN 游戏工程](../../../project.godot)的「关卡选择」进入。交互默认是 **F**，按键跟随游戏设置。玩家控制与界面由 [shared](../shared/README.md) 提供。

三处档案屏是 Sivi 抵达实验室前已有的资料。第一屏是躯壳远端重建流程，第二屏是意识独立上传的断线风险示意，第三屏是企业技术简报，展示脱敏题解和列装红眼中的相同波形。靠近屏幕按交互键查看。图形源文件在 [assets/archive](assets/archive)。三篇正式日志正文待接入。
