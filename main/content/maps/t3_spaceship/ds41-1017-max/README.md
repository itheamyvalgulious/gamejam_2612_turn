# SSV ORION — 程序化商场级星舰（Godot 4.7）

一个**完全程序化**生成的写实科幻星舰：外部壳体、引擎、舰桥全部由 GDScript 几何运算构建，
所有表面纹理由片元着色器里的数学函数（哈希噪声、fBm、Voronoi、面板场、屏幕空间导数凹凸）实时生成，
工程内**没有任何位图贴图**。内部是一座约 **300 m 长**的多层舰体，可玩主线从**船尾引擎底层区**一路走到**舰桥**，
主线经过 8 个功能区与若干支路舱室。

![hero](screenshots/ext_hero.png)

## 快速开始

```bash
cd t3_spaceship/ds41-1017-max
./run.sh                             # 等价于 DISPLAY=:0 godot --path .
```

要求：Godot **4.7.2**（Forward+ / Vulkan），本机 GTX 1650 实测可运行。

## 本轮迭代：按需精细舱室 / 近景材质 / 预生成流式

### 1. 每间舱室独立陈设 + 变体

`room_detail.gd` 为每个舱室提供**功能化、带生活痕迹**的陈设，并按房间名哈希选择
**布局变体**与**磨损等级**（顶点色 `COLOR.a` 驱动材质脏污）：

| 舱室 | 变体 |
|---|---|
| 船员舱 | A 双层床大间（6 铺 + 中央桌 + 咖啡角 + 地毯）/ B 双人包间（隔断 + 床 + 书桌 + 公共沙发厨房）/ 另有共享储物、照片墙、衣物、灭火器、急救盒 |
| 医疗舱 | A 三床病区（隔帘、输液架、床旁屏、手术灯）/ B 手术室（中央手术台、器械车、恢复床）/ C 门诊（检查台、诊桌、候诊长椅、药品柜、饮水机） |
| 机修间 | A 机加工（2 台车床、工作台、台钻、料架）/ B 焊接（焊机、气瓶、焊屏、防火垫）/ C 电子维修（双工作台、诊断台、元件架） |
| 军官舱 | 4 间单人舱 / 会议室 + 2 套间 |
| 观察室 | 酒吧休息室 / 传感器观景台（望远镜、控制台） |
| 货舱、引擎、反应堆、中庭、植物舱、舰桥、机库、水箱 | 各自附加“manifest 站/工具车/备用喷管/主管工位/商店专属陈设/灌溉歧管/损管柜/系留点”等专属细节 |

通用 `fill_perimeter` 再沿每间房的长边按 3.15 m 间隔放置储物、设备、植物、海报、垃圾桶等，
并按功能风格（hab / med / machine）抽取不同道具；大房间中央再补桌/沙发/货箱组。
所有房间共享同一套结构层（壳板→骨架→内衬→服务带→陈设→标识），但**陈设、管线走向、
破损与生活痕迹各不相同**。

近景道具库（全部程序化、米制 UV）包括：马克杯、餐具、纸张、平板、书堆、工具、便签板、
照片墙、海报、灭火器、急救盒、分类垃圾桶、清洁车、电缆盘、垂吊线缆、接线箱、仪表盘、PPE 柜、
EVA 服、工作台（台钳/工具板/台灯）、车床、台钻、零件架、料架、焊机、储物柜、胶囊床、
单人床（被褥/枕头/褶皱）、书桌（台灯/文件/平板/杯子）、沙发、厨房台、地毯、盆栽、油污/灰尘/
灼烧贴花、脚印、警示胶带、破损面板、焊缝补板等。

### 2. 近景材质

* `metal`：拉丝方向双尺度、粗细两级划痕、漆层剥落 + 底漆晕圈、面板螺栓、焊缝高度与
  蓝/紫/金热变色、油滴、积尘、锈蚀；所有细节按 `fwidth` 自动淡出，1 m 内仍保留 1–3 cm 细节。
* `plate`：甲板板缝、防滑纹、油污/磨光通道、格栅、脚底脏污；新增磨损顶点色控制。
* `wall`：模块板/裸结构/软包/瓷砖四种模式；软包加入 9× 细密绗缝、织物颗粒与编织噪声。
* `fabric`（新增）：经纬编织、起球、污渍、褪色，用于被褥、窗帘、地毯、EVA 服。
* `decal`（新增）：污渍/油池/积尘/灼烧四类透明贴花，程序化轮廓与粗糙度。
* 顶点色第四通道 `wear` 按舱室传入，驱动脏污、锈蚀、划痕强度；同一材质在不同舱室呈现不同状态。

### 3. 预生成 + 流式

* `./bake.sh`（或 `--bake`）把 19 个舱室外壳/陈设/标牌/灯光打包成 `baked/<zone>.res`，
  外壳打包为 `baked/hull.res`，并写 `manifest.json`（含版本号）。
* 正常启动时自动检测 manifest：命中则**直接实例化预生成场景**，跳过全部几何生成
  （启动 ~1.2 s）；未命中或 `--nobake` 时回退到实时生成。
* `streamer.gd` 每 0.2 s 按相机到舱室 AABB 的距离（46 m 半径）开关整个舱室节点，
  灯光与标牌随舱室一起隐藏；远处房间不再产生 draw call 与阴影开销，漫游帧时间稳定。
* 修改生成代码或材质后重新执行 `./bake.sh` 即可。

```

                       传感器、舷窗、对接环、随机 greeble、舰名文字、航行灯
  interior_builder.gd  舰内：房间壳体、结构肋、天花服务带、门洞、各功能区、光照、路线标线
  props.gd             道具库：控制台、座椅、货箱、集装箱、管道、阀门、猫道、栏杆、楼梯、

  main.gd              环境、相机、截图、HUD/导览装配

  tour.gd              主线样条导览

  plant / sky                                       植物与星云/行星/星环天空
  lib/math.gdshaderinc                              噪声与面板数学库
```

### 几何原语（`mesh_kit.gd`）

* `box_bevel` — 12 条棱全部倒角的机加工盒体（面板/设备/家具的基础）。
* `lathe` — 任意 (r, y) 轮廓旋转体：引擎喷管、储罐、反应堆环、穹顶、传感器、灯罩、水杯。
* `tube` — 平行移动标架扫掠：管道、线缆、桁架、扶手、藤蔓。
* `param` — 任意参数曲面，数值微分求法线：外壳放样、曲面屏、植物叶片、玻璃穹顶。
* `prism` — 任意 2D 轮廓沿轴挤出：稳定翼、龙骨、结构梁。
* `quad / quad_n` — 自动修正绕序，保证 Godot 前向面（顺时针）正确。
* 每个顶点带 `(part_seed, height, kind, wear)` 顶点色，供着色器做逐物件随机化与墙脚脏污渐变。
* UV 以**米**为单位，保证全舰 texel 密度一致；屏幕/发光/玻璃类材质自动切换 0–1 UV。

### 房间尺寸可调

`ShipConfig` 暴露若干参数，几何生成全程引用它们：

| 参数 | 默认 | 可调范围 | 影响 |
|---|---|---|---|
| `room_scale` | 1.0 | 0.94–1.06 | 房间墙体从模块包络向内收放 |
| `side_room_w` | 15 m | 13–18 m | 船员舱/医疗舱进深 |
| `shop_depth` / `gallery_depth` | 4 / 5 m | 3.2–5 / 4.2–6 | 中庭店铺与环廊进深 |
| `atrium_open_w` | 9 m | 8–10 | 中庭中空半宽 |
| `corridor_w` | 6.2 m | 5.2–7.4 | 主脊/服务走廊宽度 |

模块包络（长度/宽度/净高）在 `config.gd` 的 `zones` 表中，房间之间通过走廊、竖井或门厅隔开，
不会出现“挤在一起”的情况。

## 材质：纯数式纹理

所有材质位于 `shaders/`，共享 `lib/math.gdshaderinc`（哈希、value noise、fBm、turbulence、Voronoi、
错缝面板场、圆角矩形 SDF、屏幕空间导数凹凸）。

| Shader | 关键技术 |
|---|---|
| `hull` | 3.3×1.35 m 错缝装甲板、二级子板缝、铆钉环、嵌入检修盖、随机暗板/橙色警示板、沿 Z 的锈痕、热变色、贴合距离的细节淡出与 fwidth 抗锯齿 |
| `plate` | 米制错缝甲板、菱形防滑纹、格栅开孔、油污/磨光通道、SSR 友好粗糙度 |
| `wall` | 4 种模式：模块化内衬板（扶手、螺丝、通风槽、贴标）、裸结构（波纹板 + 螺栓）、软包隔音、医用瓷砖；墙脚脏污按顶点高度渐变 |
| `metal` | 拉丝/铸造/涂装三种表面、焊缝、锈斑、油滴、芯片剥漆，逐物件 seed |
| `container` | 竖向瓦楞、门框、模板喷涂、底部锈蚀 |
| `glass` | 菲涅尔透明度、脏污流痕、双面 |
| `emit` | 平整/箭头/虚线/频闪/分段/柔光面板 6 种模式，路线箭头带流动 |
| `screen` | 5 种程序化 UI：导航环、功率柱状图、心电、反应堆示意、日志滚动 |
| `plasma` | 引擎柱状等离子、反应堆球面漩涡、导管脉冲，均为加法混合 |
| `hologram` | 扫描线 + 网格 + 湍流核心 |
| `sky` | 星点（3D 哈希格）、银河带、多色星云、射线-球体求交的行星（大陆/海洋/云/冰盖/城市夜面/大气边缘）、解析星环、太阳盘 |

## 光照与后期

* 外壳与内部分别放在渲染层 1 / 2；太阳只作用于外壳层，舰内完全由数百盏局部灯与自发光面照明，
  避免阳光穿透不可见外壳把舱室照爆。
* 每区灯具布局：主走道连续灯带 + 吸顶灯 + 设备工作灯 + 应急灯；引擎区暖橙、反应堆青蓝、
  中庭暖白、植物舱蓝紫、舰桥冷蓝。
* 环境：ACES tonemap、Glow、SSAO、SSIL、SSR、体积雾（默认关闭，可在 `main.gd` 打开）、
  调整（对比度/饱和度）。
* 外壳在相机进入舰体后自动隐藏（也可用 `V` 手动切换），既保证外部写实，又避免内窥穿帮。

## 性能

* 全部静态几何按材质合批：每个功能区 ≈ 10–20 个 MeshInstance3D，总 draw call 约 200。
* 本机实测（GTX 1650，1600×900，cine 画质：SSAO + SSIL + SSR + 体积雾，vsync 关闭）：
  `--bench` 输出 **105 fps / 365k 三角形**；加载预烘焙场景启动约 **1.2 s**。1080p 截图渲染约 1–2 s/张。
* 交互模式默认 `balanced`（SSAO + Glow，关闭 SSIL/SSR/体积雾），按 `G` 可在 low/balanced/high/cine 间切换。
* 截图模式自动切到 cine 并等待 8 帧收敛。

## 已知限制 / 可继续打磨

* 舰体轮廓偏“雪茄形”，可再加入外挂舱段/机库凸包来强化剪影。
* 机修/机库等工业支路整体偏暗，后续可再加区域高棚灯与局部补光。
* 近景被褥/衣物的软体形态仍以倒角盒为主，可继续用参数曲面增加褶皱。
* 全息投影仍偏亮，可继续压 energy。
* 修改生成代码后需重新执行 `./bake.sh`，否则会加载旧的预生成场景（manifest 版本未变时）。
