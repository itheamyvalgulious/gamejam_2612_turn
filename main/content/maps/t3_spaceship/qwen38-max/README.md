# ISV Meridian —— 纯程序化「商场级」宇宙飞船（Godot 4.7.2）

任务 3 交付目录：`t3_spaceship/qwen38-max/`
全部几何、材质、纹理、天空、光照均由代码在运行时生成：**零外部美术资产、零贴图文件**。
构建耗时约 1.6 s（71 个舱室 / 45 个合并网格 / ≈27.7 万三角形 / 211 盏灯 / 13 个体雾体积 / 7 个反射探针）。

## 运行

```bash
# 交互漫游（飞行相机）
DISPLAY=:0 godot --path .

# 自动截图（48 张 1920×1080 → shots/）
DISPLAY=:0 godot --path . -- --capture

# 其他开关
DISPLAY=:0 godot --path . -- --seed=42      # 房间尺寸抖动换种子（走廊宽度恒定）
DISPLAY=:0 godot --path . -- --novolfog     # 关闭体积雾
```

交互操作：`WASD` 移动、鼠标视角、`Q/E` 升降、`F` 速度档（5/14/40 m/s）、
`[` `]` 沿主线跳转航点、`R` 回引擎舱起点、`ESC` 释放鼠标。

## 尺度与分层结构

- 船长 280 m × 型宽 100 m × 高 27.5 m（龙骨 -3.5 m → 桅顶 24 m+），3 层甲板（甲板间距 7.5 m、净高 6 m），
  可用楼面约 3.8 万 m² —— 大型商业综合体（商场）量级。
- **船体三层构造**：外壳板（超椭圆参数化放样 loft，140×48 段）+ 骨架层（每 8 m 一站的环形肋框 +
  16 条纵桁，引擎舱/机库等开敞区直接可见）+ 内衬（舱室墙板/地板/天花 slab，0.3 m 墙厚双墙咬合）。
- 外壳按世界坐标开洞：舰桥 bow 视窗带、观景舱舷窗带（含 reveal 井筒）、尾引擎喷口；
  尾部 transom 用带双圆孔的掩膜网格封盖。

## 数式材质（shader 内纯数学，无贴图）

- `panel` 三平面投影墙板：面板格+倒角+角螺栓+ Vent 缝 + 拉丝金属（高频方向噪声）+ 缝边磨损露金属 +
  底部油渍垂流（拉伸 fbm）+ 划痕 + 污垢；高度场有限差分扰动世界法线。
- `floor` 甲板：错缝钢板、防滑颗粒、磨痕、油污、可选危害斜纹/抛光变体。
- `grate` 格栅：条杠+横撑+下方反应堆辉光，随视距衰减防摩尔纹。
- `hull` 外壳：9 m 大板缝、空间污垢、尾部热灼色、微陨石坑、随机亮窗、红绿航行灯、
  机库大门/ EVA 舱口世界坐标贴花。
- `frame` 结构钢：法兰螺栓线、锈迹、边角磨损（三平面权重混合检测棱边）。
- `screen` 四种程序化 UI（数据列/心电波形/雷达扫掠/状态条）+ 扫描线 + 闪断。
- `strip` 发光条/门楣/路线带（箭头雪佛龙滚动）。
- `sky` 单层解析天空：3 层哈希星场、银心带、星云、太阳盘+冕、**解析行星**（ray-sphere：
  大陆/海洋/冰盖/云层/晨昏线/夜面城市灯/大气 limb）。
- `glass / exhaust / holo`：菲涅尔玻璃、加性尾焰、加性全息。
- 体积光：13 个 `FogVolume` 盒（引擎舱/机库/坡道/主脊/舰桥/竖井…），点光在雾中成光柱。
- 反射：7 个一次性 `ReflectionProbe`（舰桥/服务器/观景/餐厅/医疗/引擎/机库）供玻璃与抛光地板反射。

## 房间尺寸可调

`layout.gd` 中每个房间带 `jx/jz` 可调边，`_jitter()` 用种子在 ±0.9 m（x）/±2 m（z）内抖动，
并夹紧到外壳内衬线；**贴走廊的墙边永不移动**，故走廊恒宽、房间互不重叠。
`--seed=` 可复现不同布局变体。门/窗开口由「共享墙线自动配对」算法在两侧墙体同时切洞，
保证任意抖动下门洞对齐。

## 第二轮迭代（质感 / 变体 / 预生成）

### 1. 着色器质感（1–2 m 尺度成立）
- `panel v2`：漆层/裸金属双层 ——  warped-fbm 剥漆掩膜优先发生在板缝/螺栓/踢脚等磨损边；
  焊缝珠（带涟漪高光与高度）、橙皮微凹凸、竖向油污垂流（缝源种子）、灰尘按世界法线朝上分量沉积、
  双向稀疏划痕；粗糙度/金属度按层分离（漆 0.44/0.12，裸金属 0.24/0.92，湿油 0.13，干油 0.55，尘 0.85）；
  三平面高度场有限差分恢复法线浮雕（第一轮调试期曾关闭，本轮重新启用）。
- `floor v2`：错缝板+焊珠+防滑粒；交通磨痕各向异性条纹；**油洼**（warped 边缘锐利、粗糙度 0.09 镜面、
  法线压平）与外围薄油膜分离；标线漆按磨损噪声剥落；灰尘层。
- `frame v2`：涂装框材（u_paint 黄/红安全色）剥漆露金属、螺栓行下锈垂流、法兰焊珠。
- `hull v2`：日晒褪色+剥漆斑块、板缝焊珠、微陨石坑（带隆起 rim）、大尺度板面凹痕、缝内积灰。
- `glass v2`：反射/粗糙度分离 —— 抹痕+擦拭弧+底边积尘把粗糙度从 0.02 推到 0.28 并加雾度。
- `screen` 改为 lit 模式 + emission（修复特定上下文下 unshaded 变体不发光的问题）。

### 2. 舱室变体 / 破损 / 杂物
- 每间房按种子取 3 种布局原型：货舱（集装箱行 / 货架+箱堆 / 筒仓+输送线）、住舱（双侧双层铺 /
  四角铺+圆桌 / 单侧铺+隔断自习角）、餐厅（圆桌 / 长桌+长凳 / 卡座）、机房（散布 / 泵列+总管 /
  罐群+步桥）、库房、办公室同理。
- 破损层（约 1/5 房间，CARGO HOLD B 强制重度）：灼痕、碎片堆、脱落斜板、天花板垂缆、
  闪烁灯具（strip_flicker）与应急红灯。
- 杂物层：按面积散布工具箱/缆圈/灭火器/纸箱/水杯；机器近看粒度：螺栓行、铭牌屏、电缆格兰。

### 3. 预生成 + 流式加载（帧时间稳定）
- 首次运行生成后自动把 46 个网格批次写入 `cache/*.res`（15 MB）+ manifest（含 BAKE_VERSION 与 seed）；
  之后运行用 `ResourceLoader.load_threaded_*` 逐帧泵入流式装配，几何零重建。
- 启动时离船 160 m 处建"材质预热廊"渲染 4 帧，预编译全部着色器变体，消除首次可见编译卡顿；
  反射探针改为每帧挂载一个错峰烘焙。
- `--rebake` 强制重新生成并覆写缓存。

## 已知限制

- 无烘焙 GI：发光面不投射间接光（用探针+环境光近似）；
- 曲面构件为平直法线硬边（generate_normals），近看有刻面感；
- 交互模式为无碰撞飞行相机（关卡设计可用 `route` 航点与房间矩形直接生成导航）。
