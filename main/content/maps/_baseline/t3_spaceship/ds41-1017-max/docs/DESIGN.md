# SSV ORION — 设计说明

## 1. 目标与尺度

目标不是“能跑的 demo”，而是一座可被当作关卡容器使用的**商场级星舰内部**：

* 外部：300 m 级、结构分明、可辨识的写实舰体。
* 内部：约 5.5 万 m² 的五层甲板，功能区清晰，房间之间由走廊/竖井/门厅分隔。
* 主线：**船尾引擎底层区 → 舰桥**，327 m 连续可走，8 个空间节拍，每段都有独立的视觉母题。
* 支路：医疗、居住、观察、机库、机修、水箱、军官舱等，可辨认但细节预算低于主线。

尺度参照：舰体长 306 m、最大宽 70 m，与一座大型购物中心同量级；中庭挑高 20 m，
舰桥位于舰首上方的悬挑指挥塔内。

## 4. 细节预算

| 层级 | 范围 | 内容 |
|---|---|---|
| L0 主线高细节 | 引擎、货舱、两条走廊、反应堆、中庭、植物舱、舰桥 | 结构肋、天花服务带、管线、接线箱、门槛、门框、扶手、灯具、屏幕、家具、标牌、地面标线 |
| L1 支路中细节 | 船员舱、医疗、观察、机库 | 完整壳体 + 门 + 主要家具/设备 + 照明 |
| L2 支路低细节 | 机修、水箱、军官舱 | 壳体 + 设备体块 + 基本照明，不留空白 |

所有房间都由 `shell()` 统一加上：墙面管线带、接线箱、通风格栅、踢脚灯、天花桥架、
吸顶灯、门槛/门框/危险条纹。因此即使是 L2 房间也有“结构分层”可读。

## 5. 结构分层

每个舱室都按真实舰船逻辑分层：

1. **外板 / hull**：超椭圆放样壳体，128 × 168 网格，平滑法线；框肋带、边条、龙骨、附加装甲板（浮起 14 cm 并带裙边）。
2. **骨架**：房间外的墙体（0.45 m 厚）、每 3.2 m 一根竖向结构肋、横向天花梁。
3. **内衬**：模块化墙板（1.24 × 0.78 m 面板场）、扶手、踢脚、冠顶线、通风槽。
4. **服务层**：沿墙管束（青/米色）、桥架、接线箱、电子屏、应急灯、地面灯带。
5. **设备 / 道具**：控制台、座椅、容器、管道、栏杆、灯具、植物……
6. **标识**：TextMesh 立体字样 + 发光材质，涵盖区域名、舱段号、危险提示、方向指示。

## 6. 参数化曲面与数学纹理

* 外壳截面：`|x/W|^n + |y/H|^n = 1`，n = 3.35，沿 z 用 Hermite 平滑插值 W/H/中心线；法线由网格邻点叉乘求得。
* 引擎喷管：`r(t) = r0 + A(1 − e^(−kt))` 的旋转体，带加强环、内衬（翻面法线）与等离子柱。
* 反应堆：环面 + 球面等离子 + 旋转体基座 + 10 根约束立柱。
* 商店门面、控制台、座椅、床铺：倒角盒 + 旋转体 + 少量参数曲面。
* 舰桥玻璃、植物叶片、货舱龙门、穹顶玻璃条：参数化 quad 网格。

纹理由数学函数直接求值，没有贴图采样：

* 面板：错缝网格 + 逐格哈希 → 板缝、色差、暗板、警示板、检修盖、铆钉。
* 磨损：fBm / turbulence / 拉伸噪声 → 锈痕、油滴、划痕、粉尘、热变色。
* 凹凸：屏幕空间导数 `dFdx/dFdy` 的高度场扰动，无需切线数组。
* 抗锯齿：`fwidth(UV)` 自适应加宽细节，并在亚像素距离淡出铆钉/划痕/子板缝。
* 屏幕 UI：坐标变换 + 哈希 + 三角函数，5 种布局。
* 天空：3D 哈希星格 + fBm 星云 + 射线-球求交行星 + 解析星环。

## 7. 光照

* 太阳（DirectionalLight）只照渲染层 2（外壳），避免穿墙；舰内由渲染层 1 的局部灯照明。
* 每个功能区有独立的色温与照度：引擎 1800–2600 K 红橙、反应堆 8000 K 青蓝、
  中庭 3200–4000 K 暖白、植物舱蓝紫补光、舰桥 6500 K 冷蓝。
* 主走道使用连续自发光灯带 + 稀疏 OmniLight，兼顾氛围与性能；
  关键空间（反应堆核心、中庭、舰桥、引擎）开启阴影。
* HUD 采用半透明深色面板 + 青色描边 + 等宽字体，提供区域名、甲板、路线进度、快速传送、平面图。

## 8. 自动导览

`tour.gd` 沿 `ShipConfig.route`（25 个航点）做折线采样，位置与视线均做阻尼平滑，
在若干关键空间短暂停留（2.2 s），并在 HUD 显示进度与区域名。按 `F` 随时进出。

## 9. 可扩展点

* `ShipConfig.zones` 决定了每个模块的包络；修改长度/宽度/净高后，房间壳体、门洞、灯具、标线会随动。
* `room_scale`、`side_room_w`、`gallery_depth` 等参数可在不重建外壳的情况下调整房间体量。
* `props.gd` 中每个函数都是独立的程序化道具生成器，可直接复用到其他舰船或关卡。
* `MeshKit` 与材质库不依赖本项目，可作为通用程序化建模工具链复用。
