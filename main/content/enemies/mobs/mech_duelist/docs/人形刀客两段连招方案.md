# Turn 人形刀客两段连招方案

第一刀用长距离闪进接由右向左的微斜斩，第二刀留在近身范围内，从第一刀停下的左前位回斩右前。方向以 Boss 自身为准。时刻均按游戏实际播放时间计，第一刀以红闪为零点，第二刀以首刀衔接帧为零点。

## 第一刀 闪进斜斩

右脚蹬地触发机甲闪进。平移从红闪后约 0.13 秒持续到 0.34 秒，历时约 0.21 秒，距离上限为 40.8 场景单位，约 22.3 米。从蹬地开始约 0.06 秒冲出一半距离，约 0.16 秒到九成，左脚落地前收完剩余位移。完整突进沿路依次留下六道红色机体残影。红闪到左脚落地前，闪进根据玩家实时位置修正方向和落点。玩家后退时向前追，玩家靠近时在约 4.8 场景单位（2.6 米）的中心间隔截停。距离上限和场地障碍限制落点。残影保留机甲经过时的位置，落地后由脚下位置带出首刀。空中时两条腿与机体一起平移。左脚约在 0.34 秒踩实，右脚随后跟进。闪进结束后挥刀以两倍于闪进阶段的播放速率继续，约在 0.59 秒进入接招姿态。首刀斩击结束到第二刀刀气起势的间隔约 0.135 秒。

| 部位 | 起动与出刀 | 首刀衔接姿态 |
|---|---|---|
| 右脚、右踝 | 低位时承重，先抬脚跟，脚掌仍固定。闪进开始时脚掌脱离地面。 | 后脚随身体跟进，前掌点地，脚跟较轻。 |
| 左脚、左踝 | 蹬地后左腿前迈，脚底由悬空转到平踩。 | 前脚踩实，用膝髋的屈曲接住落地。 |
| 双膝和髋关节 | 右腿先推，左膝抬起后朝脚尖方向落下。左腿接受重心时稍弯膝。 | 重心偏左前腿。右腿留在背后的支撑范围内。 |
| 骨盆和下腰 | 约 0.18 秒开始向左开髋。骨盆启动躯干转向并把重心送到左腿。 | 骨盆在左脚支撑下先减速，身体仍维持低位。 |
| 胸廓、肩带与头部 | 约 0.24 秒起胸廓跟转。右肩胛随胸廓前移，右肩把上臂带向身前。头眼留在主角方向，颈部只做跟踪所需的小幅补偿。 | 胸廓和右肩略晚于骨盆停住，视线仍能盯住主角。 |
| 右上臂、右肘 | 前半段保持相对胸廓的持刀姿态。约 0.29 秒后上臂才横过胸前，肘绕自身横轴屈伸。 | 右肘仍弯着，手在左前，肘关节留出回程空间。 |
| 右前臂、右腕、手指 | 前臂绕长轴调整刃面，腕用小幅屈伸和侧偏配合。手指正握，刀柄固定在握位。 | 刀尖和刃面连续减速，保持左前方的刀路终点。 |
| 左手 | 先从地面卸重，再随身体回摆，在右肩向前时平衡转体。 | 左手留在胸廓左侧外缘，与右手和刀柄留出间距。 |

## 第二刀 左前回斩右前

第二刀是右脚斜向前迈并随挥刀起身的短斜落斩。首刀收尾的左前刀位直接作为第二刀起点。两刀连在一起时，左脚蹬地、右膝抬起和骨盆反转给玩家预告下一刀。第二刀从衔接姿势到收势用时约 0.44 秒，使用一段短的蓄转和一段更快的释放。

| 阶段 | 脚、膝和骨盆 | 胸廓、肩和头 | 肘、前臂、腕和刀 |
|---|---|---|---|
| 0.00–0.06 秒 吃住上一刀 | 左脚继续承重，左膝保持屈曲，右前掌落在后右侧。骨盆先收住上一刀的左转，重心留在两脚之间偏左。 | 胸廓沿上一刀方向完成少量余转，并逐渐停住。头仍朝向目标，左手保持在胸廓外侧。 | 右肘保持约 90–100° 屈曲。手与刀保留原来左前位置，刀尖允许继续走一小段并减速。 |
| 0.06–0.13 秒 反向开髋 | 左前掌定住并蹬地，左脚跟抬起。约 0.05 秒起右腿屈膝离地，向右前方迈出。骨盆在左腿承重时朝右转约 20–30°，从约 0.07 秒开始随迈步抬升。约 0.13 秒时右脚跟接地。 | 胸廓晚约 0.02–0.03 秒跟转，右肩带着手沿胸前展开。肩胛顺势由前伸转为回收，左肩和左手做小幅反向平衡。 | 右上臂随肩带移动，右肘从躯干外侧绕开胸甲。前臂逐步翻刃，手在腰前保持空间，随后把刀刃带进斜落轨迹。 |
| 0.13–0.33 秒 斜落释放 | 右脚从脚跟滚到全脚掌着地，右膝短暂缓冲后逐步伸展。髋部向右前方抬升，骨盆右转先放慢，胸肩随斩击逐渐立正。 | 右上臂从横过胸前的位置向右侧展开，胸廓小幅顺着刀路倾斜。头部转动幅度小于胸廓。 | 肘随上臂展开到约 65–85° 屈曲，保持余量。刃口随前臂摆正后从左前斜落到右前。腕的屈伸和侧偏各先按约 10–15° 调整。拇指与其余手指维持同一个正手握位。 |
| 0.33 秒后 收刀换步 | 右脚承重稳住上身，刀客保持回斩末势约 1 秒，随后左脚离地并开始收势。近处向侧前方迈开，目标远时接成前进步。 | 胸廓和右肩随动作减速，左手恢复到能平衡身体的位置。 | 末势的一秒保持红光。随后右肘把刀柄沿右髋收进戒备位，左手回胸前。收势约 0.28 秒，红光随之转回青蓝。 |

角度是这套机甲动画的起稿目标。骨盆与胸廓经常同时运动，但本招的发力要体现在骨盆先启动、肩带跟进、上臂和前臂随后加速。第二刀翻刃的转角由上臂转动、前臂旋转和刀的空间弧线共同完成。腕部两条小幅调节轴维持握持。 [击球三维运动研究](https://pubmed.ncbi.nlm.nih.gov/8580946/) · [躯干与上肢分段旋转研究](https://www.jstage.jst.go.jp/article/jsmeshd/2011/0/2011_169/_article/-char/en) · [前臂动态影像研究](https://pubmed.ncbi.nlm.nih.gov/20696507/)

## 动画与判定检查

- 第一刀开始独立摆臂前，检查刀柄相对胸廓的变换。看见躯干带着手走之后，才看见上臂拉开和刀身加速。
- 第二刀用首刀末帧的骨盆、胸廓、脚位、肘角和握刀四元数作起点。两刀之间连续播放和逐帧播放都应当接得上。
- 从正面检查膝盖和脚尖朝向，从侧面检查重心转移和踩实后的足底滑动。分别检查短冲、满距离闪进和近距离截停。
- 在右肩甲、右肘、持刀手和左前膝之间留出可见空隙。每一刀的有效窗口内，刃口沿刀尖实际扫过的方向领先。两刀的刀气都随真实刀路扫过，判定延伸到可见刀气外沿。第二刀使用独立的命中标记。
- 第一刀落空或玩家后撤时，第二刀沿首刀锁定的方向迈步，保留可读的近身攻击范围。第二刀已接入对战关和第一人称动作演示，回斩刀气为较短的青白弧线。刀身的亮点铺满时，刀还在抖动，刀客的头、胸、关节和刀身即转红。红光持续到第二刀挥完，突进残影也跟随机体呈红色。
