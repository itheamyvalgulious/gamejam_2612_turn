# 横扫挥斩与警戒姿势

按侧面约 0:00–0:04 复核位移、前后脚和刀路，按正面约 0:04–0:08 复核左右手与肩的走向。同一个动作又从另一侧和背后拍摄，可以交叉确认双手打开后的方向。 [Motion Actor Inc.《短兵器 · 横扫挥斩》](https://www.bilibili.com/video/BV1pZziY7EDp/)

| 参考视频侧面时间 | 脚、膝和骨盆 | 胸、手肘与刀 |
| --- | --- | --- |
| 0:00–0:00.33 | 两脚前后错开，双膝弯曲，重心留在两脚之间 | 胸微前倾，刀柄在右胸外侧。正面看，刀尖向上并略向中线倾，刀身从脸侧经过。左手抬在胸前 |
| 0:00.33–0:00.83 | 左脚留在地面，右脚先迈出。右脚落地后骨盆跟上 | 前臂与刀身先对齐，右肩向前送出，刀尖沿刀身的轴线推进。右肘在刺击末段接近伸直，随后屈肘收刀。刺中会单独结算伤害 |
| 0:00.83–0:01.58 | 右脚接住重量，左脚离地，左膝抬到髋部附近 | 持刀肘弯回、刀柄向头的另一侧抬起，刀尖走头顶外侧。左手抬到脸侧，准备在后半段打开 |
| 0:01.58–0:02.08 | 左腿向前伸并落地，左膝弯曲，右腿留在后方。骨盆先换向，随后降低 | 左肩转向前方，左手向前下方伸开，右臂从头侧打开，刀经身前扫到右后侧。头随下降向前下方看 |
| 0:02.08–0:02.67 | 保留低位和前后脚距离，后脚维持支撑 | 双臂保持打开，刀留在右后侧，末势有细小回弹 |
| 0:02.67–0:03.50 | 先从左腿起身，再收后脚恢复警戒站距 | 右肘把刀从身体外侧收回胸前，左手同步抬回警戒位 |

机甲的膝、肘按各段骨骼长度求解。两次落脚分别锁定位置，刀通过刀柄跟随手腕。检查刀身和头、胸、空手及腿部的距离，尤其关注刀柄经过头侧和刀回到胸前的阶段。
