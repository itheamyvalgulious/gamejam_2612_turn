# Turn · 单轮巡射机甲

单轮远程敌人的独立 Godot 4.7.2 工程，使用 Forward+ 渲染。

## 打开工程

在 Godot 项目管理器导入本目录的 `project.godot`，按 **F5** 进入展台。左键拖动环绕，滚轮缩放，点击「展开射击姿态」查看支脚、装甲和发射口的开合。点击「实战预览」进入第一人称单怪关。

也可以在编辑器打开 `scenes/ranged/wheel_sentry_combat.tscn` 后按 **F6**，或在本目录运行以下命令。

```sh
godot --path . res://scenes/ranged/wheel_sentry_combat.tscn
```

首次运行命令前，可以先用编辑器打开工程完成导入。实战中点击画面接管视角。WASD 移动，左键攻击，右键弹反，R 重开，Esc 暂停并释放鼠标。

## 角色资源和行为

- 模型入口是 `scenes/ranged/wheel_sentry_model.tscn`，机体、运动和光束实现在 `src/enemies/ranged/`，专用光束和预警着色器在 `gfx/`。
- 巡航速度 4.1 m/s。玩家逼近时会加速倒退，最高 10.5 m/s。炮口继续跟踪玩家，轮组会选择避开墙边的退路。
- 紫色小束可边退边打，出膛有短促闪光，可以弹反。
- 长束通常在两发小束后准备。第一发之后如果被逼近，也可能提前使用。落下支脚时锁定方向，随后蓄力约 1.85 秒。这是近身窗口，可以从约 0.92 米宽的红色预警光道旁切入。长束不可弹反。
