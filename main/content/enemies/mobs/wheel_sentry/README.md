# Turn · 单轮巡射机甲

单轮远程敌人的独立 Godot 4.7.2 工程，使用 Forward+ 渲染。

## 打开工程

在 Godot 项目管理器导入本目录的 `project.godot`，按 **F5** 进入展台。左键拖动环绕，滚轮缩放，点击「展开射击姿态」查看支脚、装甲和发射口的开合。点击「实战预览」进入第一人称单怪关。

也可以在编辑器打开 `scenes/ranged/wheel_sentry_combat.tscn` 后按 **F6**，或在本目录运行以下命令。

```sh
godot --path . res://scenes/ranged/wheel_sentry_combat.tscn
```

首次运行命令前，可以先用编辑器打开工程完成导入。实战中点击画面接管视角。WASD 移动，左键攻击，右键弹反，R 重开，Esc 暂停并释放鼠标。

## 角色资源和行为

- 模型入口是 `scenes/ranged/wheel_sentry_model.tscn`，机体、运动和光束实现在 `src/enemies/ranged/`，专用光束和预警着色器在 `gfx/`。
- 巡航速度 4.1 m/s。玩家逼近时会加速倒退，最高 10.5 m/s。炮口继续跟踪玩家，轮组会避开墙边。坠击中庭里可以沿台阶退行，遇到平台断边会换方向。
- 紫色小束可边退边打，出膛有短促闪光，可以弹反。炮口会随目标高度俯仰，楼板或墙体挡住射线时会暂缓开火。
- 长束通常在两发小束后准备。第一发之后如果被逼近，也可能提前使用。落下支脚时锁定方向，随后蓄力约 1.85 秒。这是近身窗口，可以从约 0.92 米宽的红色预警光道旁切入。红色光带会贴在射线附近的地面、台阶和平台上。长束在地面或墙体处截止，不可弹反。
- 致命斩击沿切入方向推偏机体。轮组延续受击前的旋转，轮面受击时会更快失去转速。撑地状态下，受力侧的支脚先屈折，长束和蓄力音同时切断。
- `src/enemies/ranged/wheel_sentry_knockdown.gd` 管理失衡和场景碰撞。轮面、炮架、发射口和展开支脚各有可脱落的甲片，落地火花与音效随实物接触触发。
