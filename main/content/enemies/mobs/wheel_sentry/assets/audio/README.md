# 单轮巡射机甲音效

把下列文件放进本目录，名称和扩展名用小写。表中以 WAV 为例，也可用 OGG 或 MP3。缺少的文件由游戏原有合成音补上。替换后重启「启动试玩」，在有巡射机甲的关卡里听效果。

| 文件名 | 触发动作 |
| --- | --- |
| `laser_small.wav` | 小激光发射 |
| `laser_heavy.wav` | 大激光发射 |
| `laser_warning.wav` | 大激光蓄力末段的提示 |
| `charge_loop.wav` | 大、小激光蓄力期间循环，蓄力结束或机甲被击倒时停止 |
| `armor_break.wav` | 击倒时护甲散落 |
| `rim_scrape.wav` | 击倒时轮缘擦地 |
| `body_impact.wav` | 击倒时机体撞地 |

`charge_loop` 适合使用首尾衔接的音源，游戏会随蓄力进度调整音高和音量。
