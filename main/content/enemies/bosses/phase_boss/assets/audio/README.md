# 折相音效

把下列文件放进本目录，名称和扩展名用小写。表中以 WAV 为例，也可用 OGG 或 MP3。缺少的文件由游戏原有合成音补上。替换后重启「启动试玩」，在灯墙之厅听效果。

| 文件名 | 触发动作 |
| --- | --- |
| `charge.wav` | 虚化充能提示 |
| `surge.wav` | 虚化充能的低频推进 |
| `release.wav` | 进入虚化 |
| `phase.wav` | 虚化脉冲、扑跃起跳 |
| `roar.wav` | 虚化后的咆哮 |
| `wake_growl.wav` | 苏醒低吼 |
| `impact.wav` | 践踏、扑跃和转身落地等共用的机械冲击 |
| `cannon_lift.wav` | 背炮开合等共用的机械声 |
| `cannon_charge.wav` | 背炮蓄力 |
| `cannon_fire.wav` | 背炮发射 |
| `tail_sweep.wav` | 左右扫尾 |
| `death.wav` | 击倒 |
