# VESPER // VX-02

程序化四足 ACT 主角 —— Godot 4.7.2 工程。模型、材质、骨骼、动作、长发、刀光、HUD 全部由代码在运行时生成，不依赖任何外部模型、贴图、动画或字体。

> 本工程由 `basic/character`（旧 VESPER）移入 `main/content/characters/vesper` 后重建为 v2。
> 外部 `/dat/projects/artist2dv2` 与 `main/content/levels/actdemo` 的 vendored 副本保持原样，未被修改。

### 本次调整（v2.1）

- **长发（第一轮）**：把后颈/胸口 z 下限的 `if/elif` 硬切换改成连续插值，并收小、后移肩甲碰撞球；发束贴着后颈/肩甲滑过时中段的折角（转角 33–37°）降到 9–15°，不再有“被挡住”的不可导点。
- **`I` 背刺**：剑改为**低位从身体下方/侧前方绕过**，不再翻过肩膀穿过胸腔与头部；右臂肘部按攻击阶段从前侧摆到后侧，避免整条前臂穿进骨盆。双手全程焊在剑柄上（不再释放左手）。
- **握持**：所有攻击两只手都保持在剑柄上；左侧刺的换手改为连续滑动而不是松手/抓回。
- **节奏**：`ATTACK_RATE = 1.5` 统一加速全部攻击；关键点插值由“每段缓入缓出”改为单调三次 Hermite（PCHIP），关键点之间不再逐段减速到零，动作连贯。
- **比例**：上身腰座半径与下身底盘顶部半径统一取两者平均值（腰座放大、底盘收窄），脊椎/反应环/腰环连带调整；上臂/前臂按大腿的分层装甲样式加粗，保留肘、腕独立关节与装甲叠层，不再是单根连杆。
- **蓝眼**：蓝色摄像头半球直径从 0.05 → 0.084（约 +68%），头部内腔开孔、眼窝凹陷与相机节点同步放大前移。
- **性能**：长发改为**一次性构建 + GPU 蒙皮**（骨链驱动 ribbon，不再每帧重建 ArrayMesh），并预计算头部曲面半径表、对远离碰撞体的发梢做快速排除；HUD 由每帧重绘改为 12 Hz。主场景实测从 ~27 fps（37 ms/帧）恢复到 **~52 fps（19 ms/帧）**，峰值可达 vsync 上限 60 fps。
- **长发（第二轮）**：新增前额深色下层发帘（与刘海一同蒙皮、摆动幅度更小），避免刘海抬起后露出清晰的“两层分界”；提高骨链刚度/阻尼、减弱外力响应，轻微动作不再甩飞。
- **起手式**：待机剑改为竖直略前倾的 ready guard，取代原来横放一侧的姿势；所有攻击的关键点之间加入中间帧，消除快速旋转的突跳。
- **背刺**：左手渐进抬起让位、右手始终握剑，剑从身体前下方绕过再到左后方刺出；命中轴向与测试同步更新。
- **比例（第二轮）**：上身整体 ×1.25、下身整体 ×0.85（三轴同比例），腰环世界半径与四个腿部六边形连接根中心圆半径对齐；IK 目标换算进 `LowerBody` 空间，脚仍贴地。
- **髋部/推进器**：删除大腿附近悬空裙甲片，髋根镂空环改为实心圆盘；推进器常亮微焰并随冲刺增长，限制侧向 gimbal 角，避免对侧白色尾焰柱穿模。
- **蓝眼（第二轮）**：镜头退到半透明面罩之后，加黑色孔径环与腔体内发光；shader 改为带旋转虹膜叶片、扫描环、高光斑和呼吸脉冲的自发光传感器，攻击时会聚焦/闪亮。

- **推进器（第四轮）**：单引擎 + 8 片交叠引擎盖，平时完全合上、冲刺时张开；侧向/斜向喷焰按转角缩短，避免对侧穿模。

### 第五轮

- **面罩/头腔**：面罩只渲染外表面（不渲染内侧背面），**50% 不透明度**，并在着色器里实现了**屏幕空间折射（三通道错位 = 色散）**、**菲涅尔天空反射 + 滑动高光**；头腔后半圈是一层**漆黑色哑光内衬**，所以从外面只能看到蓝色大眼睛和绿点，看不到后脑壳、脖子或内部零件。外侧照常是头发。
- **头部内容**：删除金属托环、下巴缝和腔底圆盘；玻璃腔里只剩下**蓝色 boss 眼**和绿色指示灯，所有颈部零件下移到下颌以下。boss 眼直接移植 ARC SENTINEL 的胸口感光器结构：近黑镀膜玻璃球罩 + 7 片光圈叶片（会呼吸开合）+ 细亮虹膜环 + 白热核心 + 内筒车削环 + 扫描楔形；配色调成电光蓝。直径约 0.124 m，约占头腔半径的 70%。
- **恒星**：改用 Panteleymonov A. K. 的 Shadertoy「Star / Sun」（`noise4q` 4D 噪声球体 + 暗临边 + 日珥），纯代码无 iChannel；配色调成电光蓝。星体边缘由噪声扭曲成不规则等离子体轮廓并向外抛出火舌，不再是贴纹理的整球。
- **头发**：恢复**发丝级**外观（每束横截面解析成 22/15 根独立细丝、丝间深槽）；下缘不是一排等距尖端——每束的发梢用低频簇状函数决定“尖/钝”和起收长度，相邻发束成组结束、少数留长，发片下缘再按低频分簇裁切。后发衬片是**有厚度的双层实体**（前后两面 + 缝合的边缘），并分外层长发/内层短发两排，不再是单层纸片。新增 30 束**头顶覆盖层**短刘海 + 加密加宽的前额刘海，把光滑头皮基底盖住。用 `depth_prepass_alpha` 先写深度，从后脑/发缝不会看到头壳内部。配色为珂朵莉式连续蓝渐变（深海蓝发根 → 天蓝中段 → 浅冰蓝发梢 + 沿发丝方向的柔白高光）。
- **握持**：固定为**右手在下（剑柄末端）、左手在上（护手侧）**，任何攻击都不再交换双手。
- **背刺重制**：由连续参数化路径生成（202 个密集关键帧）——竖直前上 → 绕前后轴向左翻平 → 左手向左上方抬起、剑交右手 → 右臂与剑水平绕身体竖轴转到身前、**右前臂与剑严格垂直** → 继续向前送出、身体转 41° 并后撤一步，剑保持指向正后方刺出；回收沿同一扫掠路径返回。剑格在整段中滚转到竖直，避免 0.47 m 横护手扫过胸腔。
- **推进器**：引擎盖改为真正的**虹膜光圈**——8 片金属叶片绕各自位于喷口边缘的销轴在封面内滑动，合上时完全封死喷口（含中心盖），张开时像相机光圈一样散开；打开快、关闭慢。喷焰底面烘焙在喷口平面上，任何 gimbal 角都不可能倒插进机体；盖子未打开时不显示喷焰。
- **推进器转向**：喷口在按 A/D/W/S 行走时就开始跟随移动方向缓慢转向，冲刺只是把同一偏转角推到最大，不再按 Shift 瞬间跳转。
- **验收**：新增 `qa_motion.tscn`——对每个关节采样世界坐标，要求逐帧位移不超过 FRONT_R，加速度不超过 FRONT_R 的最大值（含剑尖/双手/双肘/头）。`qa_collision` 现在把剑的**剑刃、剑柄、剑格、剑柄末端**全部纳入与躯干/头/骨盆/腿的检查，剑刃还会检查双臂；仅允许握持手与剑柄的正常包裹接触。

### 第六轮（本轮）

- **手臂比例**：上臂 `0.62 → 0.496 m`、前臂 `0.58 → 0.464 m`（世界空间肩→腕 `1.33 → 1.06 m`，**−20 %**）。所有分层装甲 / 侧甲 / 导光缝的截面向量乘 `P.arm_w = 0.86`：前臂最厚处约 **0.078 m**、比小腿（0.082 m）略细，上臂白甲宽 0.133 m 也细于大腿（0.152 m）。各层装甲的纵向偏移改写为**骨骼长度比例**（注释里保留旧的绝对米数），所以缩骨只是把层叠件整体跟着关节滑动，层与层的相对位置关系不变；肘、腕仍独立关节，骨骼分层不变。
- **肘部极点表**：手变短后，两个侧刺的“两只手都在身体同一侧”会让两条前臂互相穿插（旧版 1.33 m 手臂全靠超大肘部余量躲过去）。把原来散落在 `_solve_arm` 里的 `if` 收成 `CROSS_POLES` 表：两个侧刺分别给左右臂一个肘部方向（左肘抬到前上方、右肘压到前下方，让两条前臂一上一下错开），其余谱面继续用默认极点；权重仍随 `_special_w` 平滑淡入淡出，没有开关跳变。
- **侧刺参数**：剑柄横移收敛到新手臂能双手握住的量（`wpx` 0.46 → 0.32，起手倒把 0.46 → 0.44），旋转段把剑柄压低、柄尾从胸口下方绕过。左手仍在护手侧握把、右手仍在柄尾（`grip` 误差 0.000），剑轴仍是水平 +X，躯干 yaw 仍为 0（不转身）。
- **背刺参数**：剑刃从身体左侧离开后向中线收敛（`psi` 0.40 → 0.26），所以正后方 1.5 m 的“另一个自己”会被刺中；旧版刀尖落在自身左侧 0.25 m 外，正后方的目标会漏。
- **指示灯**：改成**黑色灯座压圈 + 半球灯珠**，位置用 `MK.beam_x` 的截面解析式（`_beam_half_w`）算出来，直接贴在前臂白色装甲的外表面上；旧版是 4 个圆盘悬在手臂外侧约 3 cm、圆盘轴向还顺着手臂，所以动作一变就明显错位。灯珠尺寸不跟着 `arm_w` 缩。
- **验收**：`qa_collision` 的手臂胶囊半径换成新的真实截面（上臂 0.069 / 前臂 0.051 / 拳 0.040 × torso 缩放）；`qa_targets` 重写为“**1.5 m 处的一个自己**”——在攻击方向上真的放一个 `Rig` 副本，用与 `qa_collision` 相同的躯干/四肢胶囊判定剑刃是否插进它身体（而不是只看刀尖到中心的距离），正/左/右/后 7 个方向谱面全部命中。

### 腿部两段 IK

设髋到足端在竖直平面内的水平距离为 $d$、高差为 $h$、大腿/小腿长度为 $L_1,L_2$，则

$$
L=\sqrt{d^2+h^2}
$$

$$
\alpha=\arccos\!\left(\frac{L_1^2+L^2-L_2^2}{2L_1L}\right),\qquad
\beta=\arccos\!\left(\frac{L_1^2+L_2^2-L^2}{2L_1L_2}\right)
$$

大腿角为基线角加 $\alpha$，膝关节角为 $-(\pi-\beta)$。静止时 $\beta\approx137.4^\circ$，所以腿是浅折角而不是直角；四足仍然按 45° / 135° / 225° / 315° 中心对称展开。

## 外观

- **配色**：冷白主装甲 + 深海军蓝副装甲 + 近黑蓝骨架 + 电光蓝能量 + 单点绿色指示灯。没有红/橙主色。
- **全金属**：所有硬表面走 `shaders/vesper_metal.gdshader`：程序化拉丝、铸造晶粒、稀疏划痕、菲涅尔边缘磨损、面板粗糙度变化；无贴图。
- **头部**：光滑弧面黑色面罩/头盔（参照流线型全盔）；没有脸/嘴/V 缝。**+X 侧**面罩内部凹进一个黑色腔体，只有一颗**蓝色带纹理的半球体**（无金属边框、无外凸镜筒）从腔底发光，能看到明显纵深；另一侧嵌一个绿色指示灯。
- **女性化上身**：窄腰、分层胸甲、深蓝胸骨缝与下胸束带、外扩髋甲；腰环比胸窄，肩线收窄。
- **背部**：旧六边形背包替换为 **矢量推进器背包**：左右两个可偏转主喷口 + 中央小喷口，蓝色内焰；冲刺时喷口朝冲刺反方向偏转并放大火焰。
- **左前臂**：3 个蓝色 + 1 个绿色指示灯，每颗都是“黑色灯座压圈 + 半球灯珠”，直接嵌在前臂外侧装甲面上（随手臂一起转，不悬空），随呼吸/动作明暗。
- **光剑**：中世纪大剑轮廓的**扁平蓝色片状光剑**：宽刃（0.205 m）+ 短尖，蓝色能量场 + 快速脉动/流动纹理 + 向外扩散的蓝色光晕；护手是 Kylo Ren 式能量护把（中央发射器 + 左右两根短能量叉），外包金属护块。

## 长发

`scripts/mech/hair.gd` 使用**真骨骼链 + `SpringBoneSimulator3D`**：

- 每个发束是一条 8 节骨骼链；骨骼由 `SpringBoneSimulator3D` 驱动，带重力、阻尼、刚度、外部风力和头部/躯干碰撞球/胶囊。
- Skeleton3D 是 `top_level`，每帧对齐到 head 的**无缩放**世界变换，避免躯干 0.88 缩放污染物理长度。
- Godot 4 会在每帧蒙皮后把 bone pose 恢复成未修改的备份，因此发丝网格在 `skeleton_updated` 信号里读取模拟后的骨骼姿态并重建 ribbon。
- 发色冷白 → 冰蓝 → 电光蓝，约 1/6 的挑染为冷白；无贴图，双面 unshaded ribbon。
- 静止时自然下垂；冲刺/转身/回旋时被惯性和风力甩动。

- 正面四式刀尖 $z\le -2.07$ m，刀尖距身体中心约 2.1 m。
- 侧刺刀尖 $x=+2.01$ m（$y=1.73$），躯干 yaw 恒为 0（不转身）；剑柄横移 0.32 m 是双手都能握住的极限。
- 背刺刀尖 $(-0.03,+1.57,+1.28)$ m：正后方，横向只偏出中线 3 cm。
- 重击刀尖最高 3.40 m，命中后刀尖压到地面附近（后续帧会短暂压入地面约 0.14 m，作为重击“咬地”表现）。
- 回旋累计扫过 7.42 rad（>360°），刀身水平误差 0.09 m。

### 回旋的角速度

`SPIN` 的中段不用逐关键点缓动（否则每个关键点都会减速到 0），而是用梯形角速度曲线：

$$
\theta(u)=
\begin{cases}
k\,r\,(x^3-\tfrac12x^4), & u<r,\ x=u/r,\\[2pt]
k\,r/2+k(u-r), & r\le u\le 1-r,\\[2pt]
1-k\,r\,(x^3-\tfrac12x^4), & u>1-r,\ x=(1-u)/r,
\end{cases}
$$

其中 $r=0.24$、$k=1/(1-r)$。中段角速度恒定，起止平滑。

### 冲刺 / 跳跃

- 矢量冲刺方向由本地输入给出，支持前、左、右；冲刺距离 2.0 m，时长 0.28 s，冷却 0.5 s。推进器喷口随冲刺方向偏转。
- 跳跃是 `TAKEOFF / AIR / LANDING` 三态，空中不依赖固定时长，脚底触地即进入落地。

## 已知边界

- 视觉风格是硬表面 + 程序化微表面的风格化机甲，不是 3A 扫描级资产；近景能看到多边形棱面和重复的装甲块。
- 长发是约 120 条骨链 ribbon（长度约 1.1–1.4 m），shader 再把每束解析成细丝并加发丝级边缘；极近景仍能看到 ribbon 的多边形轮廓，且头顶/刘海处的头皮基底是一整片光滑曲面。
- 四足 IK 对平面场地做世界锁定；复杂地形需要加足端射线/坡度适配。极端前倾的攻击瞬间爪尖会短暂入地 ≤1.5 cm。
- 面部/手指没有独立关节；手是机甲拳，握持轴对齐剑柄；右手固定在下（柄尾）、左手固定在上（护手侧）。
- 手臂长度的**下限由侧刺决定**：0.34 m 长的剑柄上两只手的位置是固定的，向侧面双手刺出时左手要跨到身体另一侧，1.06 m 的肩→腕已经是“两只手都还能握住、且两条前臂不互相穿插”的极限；再短就只能放弃侧刺的双手握持或缩短剑柄。
- 没有音频、贴图、动画文件；全部由代码生成。
