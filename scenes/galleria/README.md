# ORION // Galleria 坠击中庭

沿用 `scenes/cargo_hold2` 的 Godot 4.7.2 独立关卡管线。玩家从商业中庭的高台生成，跃入下层战斗区；敌人为 **4 个基础近战 + 2 个远程**。完整工程在本目录，可单独运行。

## 启动

Windows 双击 `run.cmd`。脚本会先导入字体和脚本类，避免首次运行时缺少导入缓存。

```powershell
.\run.cmd
.\run.cmd -Editor
.\run.cmd -ImportOnly
# 也可手动指定 Godot：
.\run.ps1 -GodotPath 'D:\Godot\Godot_v4.7.2-stable_win64_console.exe'
```

也可用 Godot 打开本目录的 `project.godot`，等待导入结束后按 F5。`.godot/` 是缓存目录，不是启动文件。Linux / macOS 使用 `GODOT_BIN=/path/to/godot bash run.sh`。

## 高台进攻

1. 玩家生成在高台圆环内，面向开放跃下口。沿地面箭形灯走向边缘，Space 起跳或直接走下边缘。
2. 从高台进入空中后按 **鼠标左键**，发动带刀身动作与激光轨迹的坠击；落地形成冲击环，对半径 7 场景单位内、无遮挡的敌人造成 90 点伤害。
3. 坠击需要从至少 6 单位高处起步，并实际下落至少 3 单位；普通原地跳跃不会反复触发冲击伤害。无需按键也可正常落地，继续使用原有方向斩和弹反。
4. 落地后利用展示台和立柱绕侧，接近后排远程怪。右侧宽阶梯可返回高台，重新选择下落位置。
5. 清空 6 个敌人通关；R 重开，死亡自动重开。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 鼠标 | 移动 / 转动视角 |
| Space / Shift | 跳跃 / 冲刺 |
| 鼠标左键 | 地面攻击；高台下落时发动坠击 |
| 左键 + A / D / S | 方向斩 |
| 鼠标右键 | 弹反、举刀 |
| Q / E | 重斩 / 回旋斩 |
| V / Tab | 第一、第三人称切换 / 第一人称视野遮罩 |
| R / Esc | 重开 / 暂停及按键设置 |
| F1 / `~` | HUD 开关 / 手感参数 |

保留 demo 的视线格挡：基础怪会格挡画面内的普通攻击，侧斩、回身斩与回旋斩可攻击视野外目标。高台坠击提供另一种进攻方式。

## 场景与实现

上层平台有完整底板与支撑结构，中央跃下口保持开放，两侧有实体护栏。28 级浅踏步形成返回路线；下层展示台、门窗立框、灯具吊杆、检修件及中央金属装置均有实体厚度。使用冷钢、暖色展示台、青色导向和少量品红商业灯；圆柱灯管配连续表面发光照明，固定曝光，不使用随相机切换的灯光开关。新增舱壁管路、检修盖、立柱底座、柜体锁固件、平台底部结构与整段照明，保留星舰冷钢和青色基调。涂装增加运行时细节法线和微观粗糙度。

灯管采用连续发光内芯、透明玻璃外管和金属端头，整段保持恒定发光。发光几何体通过 VoxelGI 照亮周围表面，配合整条灯具的反射，不再使用沿线排列的点光源。反射探针只收录静态环境，角色由实时屏幕空间反射处理。阶梯内侧与立柱间的通行余量已扩大；掩体、车体类实体顶部具备落地支撑，平台底梁和装置外环也有对应碰撞。

- `src/encounter/arena.gd`：高台、阶梯、展示台、商铺、敌人布局。
- `src/encounter/art.gd`、`gfx/encounter/`：与货舱一致的实体构件和程序化材质。
- `src/encounter/level.gd`：高度支撑、扫掠碰撞、坠击、寻路和独立通关流程。
- `src/vesper/mech_rig.gd`：加入可变地面高度，兼容高台起跳、落地和接触阴影。
- `src/game/projectiles.gd`：三维实体遮挡，箭可越过低掩体，平台也能挡箭。
- `src/game/camera.gd`：结合关卡三维实体限制相机，避免把矮掩体当作无限高墙。

平台与阶梯的渲染、支撑和碰撞来自同一组尺寸。无场景文字标注，不通向飞船其他房间。保留 `run.cmd`、`run.ps1`、`run.sh` 启动方式；提交时不要加入 `.godot/`、截图、日志和临时测试脚本。

霓虹照明首次启动时自动生成，缓存存放在 Godot 的 `user://` 用户数据目录；后续启动复用缓存，重开关卡无需重新生成。修改环境或灯管源码后自动更新缓存。照明使用 Forward+ 渲染器。
