# ORION // 霓虹街区

沿用 `scenes/cargo_hold2` 的 Godot 4.7.2 独立关卡管线：程序化实体场景、Forward+、四足刀客、方向斩、视线格挡与弹反。完整工程在本目录，不依赖其他关卡的文件。

## 启动

Windows 双击 `run.cmd`。脚本先导入字体和脚本类，再启动游戏，首次导入可能稍慢。

```powershell
.\run.cmd
.\run.cmd -Editor
.\run.cmd -ImportOnly
# 引擎不在 PATH 时，可指定路径：
.\run.ps1 -GodotPath 'D:\Godot\Godot_v4.7.2-stable_win64_console.exe'
```

也可用 Godot 导入本目录的 `project.godot`，等待资源导入完毕后按 F6 运行 `main.tscn`，或 F5 运行整个工程。`.godot/` 是缓存目录，入口文件是 `project.godot`。

Linux / macOS：`GODOT_BIN=/path/to/godot bash run.sh`。

## 关卡

- 敌人：3 个基础近战、2 个远程、1 个固定点位位移怪。
- 玩家从街区南端生成，中央大道与左右店铺侧巷互通。售卖亭、装甲工程车、设备柜形成交错掩体，可绕侧接近远程怪。
- 位移怪在 4 个发光圆环之间随机移动；进入玩家视野立即位移，带激光消散和重组效果，抵达后有 1.35 秒可攻击窗口。
- 近战敌人沿可通行网格绕开掩体，并保持彼此间距。远程怪保持距离、蓄力射击，实体遮挡会阻止开火和飞行物穿透。
- 清空全部敌人通关；死亡自动重开，R 可随时重开。本工程只包含当前街区，不切入其他场景。

## 美术与代码

以 demo 的雨夜城市为基础，采用暗红商业灯、冷白工作灯、雨幕、排水蒸汽和带雨点涟漪的湿路积水。车体细化了独立装甲、轮胎胎纹、轮毂螺栓、散热格栅、动力模块、车顶传感器和有投射光束的前灯。柜体和车辆涂装使用运行时生成的细节法线贴图，结合擦痕、掉漆和粗糙度变化。

霓虹灯管采用连续发光内芯、透明玻璃外管和金属端头，发光几何体通过 VoxelGI 照亮周边表面，不再使用沿线排列的点光源；屏幕空间反射和静态环境反射保留整条灯管的倒影。静态反射只收录环境，避免角色移动后留下旧倒影。所有细节保持实体厚度，无悬浮场景文字。

车辆轮胎、车身、传感器和顶部设备使用对应碰撞包围体，掩体顶部支持落地，避免跳跃后穿入模型。

| 路径 | 职责 |
| --- | --- |
| `src/encounter/arena.gd` | 街区建筑、掩体、敌人和位移点布局 |
| `src/encounter/art.gd` | 实体构件、材质、灯管和照明 |
| `src/encounter/level.gd` | 战斗流程、寻路、扫掠碰撞、相机与视线 |
| `src/encounter/*enemy.gd` | 基础、远程、位移怪行为 |
| `src/game/`、`src/vesper/` | 沿用 demo 的玩家、武器、机甲和战斗系统 |
| `gfx/encounter/` | 环境材质着色器 |

场景生成尺寸同时用于碰撞体，禁止单独移动视觉资产而遗漏对应碰撞。修改后运行 `run.cmd -ImportOnly`，再实际启动检查。提交源码、`.uid` 和字体导入配置；不提交 `.godot/`、截图、日志或临时测试脚本。

霓虹照明首次启动时自动生成，缓存存放在 Godot 的 `user://` 用户数据目录；后续启动复用缓存，重开关卡无需重新生成。修改环境或灯管源码后自动更新缓存。照明使用 Forward+ 渲染器。
